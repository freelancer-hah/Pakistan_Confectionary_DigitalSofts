# Pakistan Confectionary - DigitalSofts

This repository contains the complete solution for Pakistan Confectionary, including both the Web Application and the Mobile Application.

## Project Structure

```text
Pakistan_Confectionary_DigitalSofts/
├── web-app/         # Next.js Web Application (Storefront, Admin Panel, Inventory)
├── mobile/          # Expo / React Native Mobile Application
└── supabase/        # Database Schemas & Migrations
```

---

## 🌐 Web Application (`web-app`)

Built with Next.js 15, Tailwind CSS, Supabase, and Firebase.

### Getting Started

```bash
cd web-app
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the web app.

---

## 📱 Mobile Application (`mobile`)

Built with Expo and React Native.

### Getting Started

```bash
cd mobile
npm install
npx expo start
```

---

## 🗄️ Database (`supabase`)

Contains the database schema definitions and setup SQL scripts for Supabase.
